# Latest Prior-Art Watch — 2026-08-29

## Newly hardened boundaries

1. **Context-dependent threshold decryption (ASIACRYPT 2025 / ePrint 2025/279):** decryption shares can be isolated by a cryptographic context. KEYSTONE therefore does not claim context binding or share-isolation as new. The current MPP uses context-bound proof transcripts; a production paper must distinguish that from full context-dependent threshold decryption.
2. **UQ-Vote (surfaced accepted IEEE Access version, DOI 10.1109/ACCESS.2026.3725080):** consensus-finalized authorization, public bulletin-board logging, threshold-share release, and liveness/fault evaluation already appear in an adjacent voting setting. Final bibliographic metadata must be verified against IEEE Xplore before submission.

## Surviving KEYSTONE claim

The defensible contribution is the combination of:

- a rollup-specific property separating ciphertext DA from deadline-bounded authorized decryptability;
- non-production, canonical canary sampling of a private threshold service;
- exact catastrophic false-accept bounds and repeated-audit conditions;
- correlation/failure-domain-aware placement and sampling evaluation;
- explicit measurement of the selective-withholding gap; and
- a reproducible encrypted-AI-rollup dispute prototype.
